# 轮腿机器人仿真

当前完整功能入口是 `advanced_control.py`，运行模型是 `real_wheelleg_balance.xml`。原始坐标参考 `real_wheelleg_fixed_base.xml` 保留用于追溯，不作为当前控制入口。

```powershell
python advanced_control.py --gamepad
# 查看高 20 cm、长 40 cm 的飞坡，初始位置后移，留出助跑空间
python advanced_control.py --gamepad --terrain launch --start-y -7
# 组合场地
python advanced_control.py --gamepad --terrain course
```

**20 cm 飞坡已配置，但当前控制器尚未通过该陡坡的稳定飞越测试。** 平地 2 m/s、0.20 m 腿长和深蹲跳跃已验证。详细测量与失败边界见 [当前验收](速度跳跃与飞坡验收.md)。

| 操作 | 功能 |
|---|---|
| LB＋左摇杆前后 | 目标速度 ±2 m/s，加减速限制 0.6 m/s² |
| LB＋左摇杆左右 | 转向角速度，最大 0.5 rad/s |
| LB＋方向键上下 | 目标腿长 0.20–0.35 m |
| LB＋A | 静止稳定接地时请求深蹲跳跃；约蹲至 0.20 m 再推蹬 |
| B / START | 急停 / 失能后的电机起身 |

不接手柄时去掉 `--gamepad`。键盘 ↑/↓ 每次改变速度 0.2 m/s，←/→ 转向，空格停车，W/S 调腿长，J 跳跃，E 急停，R 电机起身。键盘速度是累加式，松键不会自动清零；手柄松开 LB 会减速停车。

腿长是髋轴到轮心的距离，不是机体离地高度。选择 0.20 m 作为本次下限，未把 0.15 m 直接开放为平衡工作点。实际腿长在动态过程中允许少量误差。

本次深蹲跳跃的轮底离地约 **21.4 cm**，落地后重新稳定停车。推力提高并不保证可恢复落地，因此没有使用实测失败的最大推力。
